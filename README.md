# vable-swift

Public binary releases for the Vable AI iOS SDK.

This repository hosts pre-built `VableAI.xcframework` binaries consumed by Swift Package Manager and CocoaPods. Source code is not included.

## Installation

### Swift Package Manager

Add the package in Xcode via **File → Add Package Dependencies**:

```
https://github.com/vable-ai/vable-swift-sdk
```

The SDK package resolves its binary from this repo automatically.

### CocoaPods

```ruby
pod 'VableSwiftSDK'
```

## Releases

Each release contains a single asset: `VableAI.xcframework.zip`.

Releases follow [semantic versioning](https://semver.org). See the [Releases](https://github.com/vable-ai/vable-swift/releases) page for changelogs and downloads.

## Source

The SDK source code is maintained in a private repository. This public repo exists solely to host binary release assets.
